# Overview

In this project I learnt the language of C++ by creating an app that helps a user keep a log of their run.

In this project a user can enter in some information on a recent run/jog they did. Information such as the distance, time, pace, etc. This information is then saved on a file (csv) and later used to display a summary of all the information in the csv file.

I am entry level runner and I enjoy seeing my progress. This keeps me motivated as I accumalate and see the progress I have made. I have created this app to achieve the purpose of keeping a log of a runner's recent jogs.
